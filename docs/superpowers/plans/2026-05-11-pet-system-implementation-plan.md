# Claude Pet 实现计划

## 概述

基于设计文档，将实现计划分为 7 个阶段，每个阶段可独立测试。

---

## 阶段 1: 项目初始化

### 目标
创建 VSCode 扩展项目骨架。

### 步骤
1. [ ] 使用 `yo code` 生成扩展项目
2. [ ] 配置 `package.json`:
   - 添加命令定义 (`claude-pet.*`)
   - 配置 Webview 面板
   - 设置图标和说明
3. [ ] 创建目录结构:
   ```
   src/
   ├── extension.ts      # 入口
   ├── webview/          # WebView 相关
   │   ├── pet.html
   │   ├── pet.ts
   │   └── styles.css
   ├── core/             # 核心模块
   │   ├── PetEngine.ts
   │   ├── SpriteManager.ts
   │   ├── Renderer.ts
   │   └── Storage.ts
   └── types/
       └── index.ts      # 类型定义
   resources/
   └── sprites/          # 内置序列帧
   ```
4. [ ] 安装依赖 (vsce, typescript 等)

### 产出
可运行但空白的 VSCode 扩展项目。

---

## 阶段 2: 基础 WebView 面板

### 目标
创建可显示的宠物悬浮窗口。

### 步骤
1. [ ] 在 `extension.ts` 中创建 WebView 面板
2. [ ] 创建 `pet.html` 基础结构:
   - Canvas 元素
   - 基础 CSS 样式
3. [ ] 建立 extension ↔ webview 通信通道
4. [ ] 测试面板显示/隐藏命令

### 产出
点击命令可显示/隐藏空白 WebView 面板。

---

## 阶段 3: Canvas 序列帧渲染

### 目标
在 Canvas 上播放序列帧动画。

### 步骤
1. [ ] 实现 `SpriteManager`:
   - 加载序列帧图片
   - 管理帧缓存
2. [ ] 实现 `Renderer`:
   - 绑定 Canvas
   - 逐帧绘制
   - 控制帧率 (8fps)
3. [ ] 创建占位序列帧（纯色方块）用于测试
4. [ ] 测试动画播放

### 产出
Canvas 上能播放简单的帧动画。

---

## 阶段 4: 宠物状态机

### 目标
实现宠物状态管理和状态切换逻辑。

### 步骤
1. [ ] 定义 `PetData` 和 `PetConfig` 类型
2. [ ] 实现 `PetEngine`:
   - 属性初始化
   - 状态计算
   - 衰减规则 (每分钟饥饿度 -2)
3. [ ] 实现状态优先级逻辑
4. [ ] 连接状态机到渲染器（状态变化触发动画切换）
5. [ ] 测试各状态切换

### 产出
宠物根据属性自动切换动画状态。

---

## 阶段 5: 数据持久化

### 目标
宠物数据保存到本地，卸载不丢失。

### 步骤
1. [ ] 确定存储路径: `%USERPROFILE%/.claude-pet/`
2. [ ] 实现 `Storage` 模块:
   - `loadConfig()`: 读取配置
   - `saveConfig()`: 保存配置
   - 自动创建目录
3. [ ] 配置读写逻辑:
   - 位置、大小变化时自动保存
   - 宠物属性变化时保存
4. [ ] 实现配置热更新（配置文件修改后自动重载）

### 产出
宠物数据持久化，卸载重装后数据保留。

---

## 阶段 6: 拖拽和缩放

### 目标
悬浮窗可自由拖拽和缩放。

### 步骤
1. [ ] WebView 内实现拖拽:
   - 监听 mousedown/mousemove/mouseup
   - 通过 postMessage 通知 extension 更新位置
2. [ ] WebView 内实现缩放:
   - 拖拽边缘/角落调整大小
   - 通知 extension 更新尺寸
3. [ ] extension 保存位置/尺寸到配置
4. [ ] 启动时恢复上次位置和尺寸

### 产出
悬浮窗可拖拽、缩放，关闭重开后保持位置。

---

## 阶段 7: 内置序列帧与打包

### 目标
添加默认宠物序列帧，完成插件打包。

### 步骤
1. [ ] 创建内置序列帧资源:
   - cat/ (idle, happy, sad, eating, sleeping, playing)
   - dog/
   - rabbit/
   - bird/
2. [ ] 将资源打包到扩展中
3. [ ] 测试不同宠物类型切换
4. [ ] 使用 `vsce package` 打包
5. [ ] 测试打包后的扩展

### 产出
完整的可发布 VSCode 扩展。

---

## 依赖关系

```
阶段1 (项目初始化)
    ↓
阶段2 (WebView面板) ← 需要阶段1
    ↓
阶段3 (Canvas渲染) ← 需要阶段2
    ↓
阶段4 (状态机) ← 需要阶段3
    ↓
阶段5 (持久化) ← 可与阶段4并行
    ↓
阶段6 (拖拽缩放) ← 需要阶段2,5
    ↓
阶段7 (资源打包) ← 需要所有阶段
```
